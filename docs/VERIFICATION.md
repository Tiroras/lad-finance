# Проверка приложения

Дата: 11 сентября 2026 года. Среда: macOS, Node.js 22.21.1, Expo SDK 57, React Native 0.86.3.

| Проверка                                                                   | Результат                                         |
| -------------------------------------------------------------------------- | ------------------------------------------------- |
| TypeScript: `npm run typecheck`                                            | Без ошибок                                        |
| Финансы, CSV, миграция и шифрованное хранилище: `npm test`                 | 43 теста пройдено                                 |
| Пользовательские сценарии: `PLAYWRIGHT_CHANNEL=chrome npx playwright test` | 13 сценариев проверено успешно                    |
| Совместимость зависимостей: `EXPO_OFFLINE=1 npx expo install --check`      | Соответствуют локальной таблице совместимости SDK |
| Конфигурация Expo для iOS / Android / Web                                  | Прочитана без ошибок                              |
| `EXPO_OFFLINE=1 npx expo export --platform all --max-workers 2`            | Экспорт завершён для всех трёх платформ           |
| Консоль и ошибки JavaScript при съёмке экранов                             | Ошибок не обнаружено                              |
| Иконки                                                                     | iOS и Android: 1024 × 1024; favicon: 64 × 64      |

Финансовые тесты проверяют точность копеек, ввод на русском, границы месяцев, резервирование, отрицательные остатки, переводы на цели, оплату без двойного учёта, перенос даты оплаченной подписки и отклонение повреждённых резервных копий.

Новые проверки покрывают просрочки через границу месяца, дату начала учёта, пропуски и сохранение прошлых условий при изменении платежа, локальное время напоминаний и ограничение очереди. CSV проверяется на кавычки, переносы строк, кодировки, приход/расход, неоднозначные переводы, повторы и конфликтующие ID. Ядро хранилища проверяется с настоящим AES-GCM Node.js и тестовыми адаптерами: перенос открытых данных, Unicode, новый IV, повреждение тега, потеря ключа, отказ записи и восстановление.

Пользовательские сценарии проверяют навигацию, скрытие баланса, создание → перезагрузку → поиск → изменение → удаление операции, симулятор без изменения данных, пополнение цели, лимиты и подписки, перенос даты оплаченного платежа, экспорт и подтверждённый импорт, переход из деморежима к собственному учёту. Проверены размеры 320, 390 и 1440 CSS-пикселей. Дата в браузерных тестах фиксирована для воспроизводимости.

Добавлены сценарии: пропуск → возврат → оплата просрочки; предпросмотр CSV → выбор строк → импорт → повторный файл без дублей; связывание уже импортированного расхода с платежом без нового списания; подтверждённое восстановление повреждённого хранилища. Новые экраны также просмотрены визуально; при съёмке ошибок консоли и горизонтального переполнения на 320/1440 px не обнаружено.

После разделения `Application` и `screens` повторно проверены типы, модульные и браузерные сценарии, экспорт трёх платформ. Для обзора, операций, бюджетов, целей, платежей, аналитики и формы операции сделано по два снимка до и после переноса: при ширине 390 и 1440 px. Все 14 пар PNG совпали побайтово. Провайдеры, формы и блокировка сохранили порядок вложенности; типы навигации вынесены в `src/navigation/types.ts`.

Экспорт в `dist/` содержит Hermes-пакеты iOS и Android и веб-предпросмотр. Это **не установочные APK / IPA**. Нативная компиляция Xcode / Gradle, системный обмен файлами и клавиатура на физических телефонах не проверялись; iOS Simulator в рабочей среде недоступен. Профили для последующей сборки находятся в `eas.json`.

На реальных устройствах ещё нужно проверить Face ID/отпечаток/системный код, отмену входа, блокировку с открытой формой и после системного выбора файла, Keychain/Keystore после перезапуска, защиту предпросмотра и уведомления при закрытом приложении. Их нативные адаптеры прошли TypeScript и экспорт, но браузерные тесты эти системные функции не подтверждают. Face ID проверяется в собственной сборке, не в Expo Go.
