# Импорт банковской выписки

В профиле откройте «Импортировать банковский CSV». Файл обрабатывается на устройстве; сервер и банковские пароли не нужны. Форматы конкретных банков не объявляются сертифицированными: мастер позволяет сопоставить их колонки вручную.

1. Выберите CSV/TSV до 2 МБ, не более 5000 строк и 50 колонок. Поддерживаются UTF-8 с BOM и без, Windows-1251, разделители `;`, `,` и табуляция. Можно указать строку заголовков после преамбулы банка.
2. Выберите повседневный счёт. Начальный остаток должен отражать баланс **до** импортируемой истории. Предпросмотр показывает, как изменится рассчитанный остаток; приложение не подменяет начальный остаток автоматически.
3. Сопоставьте дату, описание и сумму. Для одной суммы задайте значение положительного знака; для раздельных колонок — приход и расход. При наличии выберите валюту, статус, категорию, тип и ID банка.
4. Проверьте строки. Можно снять выбор, уточнить тип и категорию, указать второй свой счёт для перевода. Ошибки и повторы не импортируются.
5. Нажмите «Импортировать … операций». Существующие операции сохраняются, выбранные добавляются одним обновлением.

Даты: `YYYY-MM-DD`, `DD.MM.YYYY`, варианты со временем; для `/` явно выбирается порядок дня и месяца. Дата должна быть от 2000 года и не позднее сегодняшней. Суммы — в рублях, до двух десятичных знаков; пробелы между тысячами допустимы, запятые и точки используются только как десятичный разделитель. Другие валюты и неподтверждённые статусы отклоняются. Если колонка валюты отсутствует, пользователь явно работает с рублёвой выпиской.

Повторы с ID сверяются по счёту и ID банка. Без ID используется количество совпадений по счёту, второму счёту перевода, дате, типу, сумме и нормализованному описанию. Совпадения с вручную добавленными записями тоже пропускаются. Разные суммы под одним ID отклоняются. Одинаковые строки внутри файла без ID считаются отдельными операциями: проверьте их вручную. В выписках с изменившимися описаниями или разным набором одинаковых операций автоматическое сопоставление без ID может быть неоднозначным.

Потенциальный перевод не превращается автоматически в расход. Подтвердите его назначение в строке: перевод другому человеку может быть расходом, между своими счетами — переводом. Перевод из накоплений на повседневный счёт разрешён только в пределах свободных денег, не закреплённых за целями. Ручной ввод и CSV проходят общую проверку; неуспешная проверка пакета не сохраняет его частично. Оплаченный из выписки регулярный платёж можно связать с расходом в календаре, не создавая второй расход. Полученный доход можно связать с планом дохода в разделе «Прогноз», чтобы он повторно не прибавлялся к будущему остатку.

[Пример с рублёвыми операциями](examples/statement.csv). CSV-формулы остаются обычным текстом и не исполняются. Временная нативная копия выбранного файла удаляется после чтения, в том числе при ошибке проверки.
