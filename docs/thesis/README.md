Подготовлено для проекта «Лад» на 21.09.2026. Рабочая тема — «Разработка мобильного приложения для управления личными финансами „Лад“»; утверждённая формулировка темы отдельно не предоставлена.

- [Глава в Word](Глава_1_Лад.docx) — редактируемый документ со стилями заголовков, таблицей, формулами, рисунками и ссылками на источники.
- [Глава в PDF](Глава_1_Лад.pdf) — экспорт Word-документа через Pages для просмотра и проверки вёрстки.
- [Текст в Markdown](chapter-1.md) — исходный текст для последующего редактирования.

## Основания оформления

Содержание составлено по файлу `ВКР_2024_v2 (2).doc`: методическим указаниям по выполнению ВКР бакалавра направления 09.03.04 «Программная инженерия», ИжГТУ, 2024. Сохранены пять обязательных подразделов первой главы: общее описание продукта, функциональные требования, данные, внешние интерфейсы и нефункциональные требования.

Параметры оформления взяты из `metodichka_po_oformleniu_v3.pdf`: «Оформление контрольных работ, рефератов, курсовых работ и проектов, отчетов по практике, выпускных квалификационных работ», Воткинский филиал ИжГТУ, 2018, с. 4, 8–14.

Анализ аналогов основан на официальных материалах, а не на собственном тестировании платных продуктов. Целевые значения производительности сформулированы как критерии будущей приёмки; результаты измерений на физических устройствах не заявляются.

## Перенос в общую пояснительную записку

Файл содержит только первую главу и относящиеся к ней источники. При включении в общую записку продолжите её сквозную нумерацию страниц: в самостоятельном файле она начинается с 1. Перенесите источники в общий список и согласуйте номера ссылок, если перед главой уже цитировались другие материалы. Заголовки оформлены стилями Word и подходят для автоматического оглавления всей записки.

Титульный лист, введение и сведения о студенте и руководителе в этот документ не добавлялись. Отдельный подраздел интерфейсов оборудования не требуется: самостоятельного внешнего оборудования у приложения нет. Рекомендация методички об объёме 30–50 страниц относится ко всей основной части ВКР, а не только к первой главе.

Для существенных правок текста обновите Word-документ и повторно экспортируйте PDF: Markdown и PDF не синхронизируются с Word автоматически.
