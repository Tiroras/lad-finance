# Категории и подкатегории

Откройте **План → Бюджеты → Категории и подкатегории** либо одноимённую кнопку в профиле. Можно создать категорию, выбрать название, значок и цвет. Для подкатегории при создании выберите «Внутри: …». Поддерживаются два уровня, до 200 категорий вместе с архивом.

Основная категория имеет месячный бюджет. Все её подкатегории используют этот же лимит: расход 500 ₽ в «Дом / Ремонт» увеличивает расходы «Дом» ровно на 500 ₽. Отдельного бюджета у подкатегории нет. Аналитика группирует расходы по основным категориям; на экране операций доступны фильтры по основной категории со всеми подкатегориями или по отдельной подкатегории.

Названия одного уровня должны различаться без учёта регистра и пробелов по краям. Переименование сохраняет ID и связи с историей; новое имя видно в старых операциях. Уровень и родитель после создания не меняются, чтобы перенос категории не менял распределение прошлых расходов между бюджетами.

Архивирование основной категории переносит в архив и её подкатегории. История остаётся доступной в операциях и аналитике, а месячный лимит архивной категории не входит в текущий бюджет. В новых операциях и автоматическом выборе CSV архивные категории скрыты. У исторической операции можно сохранить прежнюю архивную категорию при редактировании. Действующие регулярные платежи продолжают учитывать прежнюю категорию, в том числе при отметке оплаты.

Вернуть основную категорию и нужные подкатегории можно по отдельности. Сначала возвращается основная категория. Категория с ID `other` остаётся доступной как резервный вариант для нераспознанных операций; её нельзя архивировать. Физического удаления категорий нет.

Финансовый формат обновлён до версии 2. Чтение версии 1 переносит имеющиеся категории без изменения ID и операций. Проверка резервной копии отклоняет неизвестные ссылки, циклы, третий уровень, повторяющиеся ID/названия и ненулевой бюджет подкатегории. Категории, родительские связи и архив входят в JSON и защищённую копию.
