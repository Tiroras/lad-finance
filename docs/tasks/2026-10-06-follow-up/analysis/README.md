## Что завершено, а что требует выполнения

- Записки A09, A26 и B11 выполнены. A26 не означает реализацию merge и не закрывает исходный пункт массового редактирования, который пользователь исключил.
- Для T02–T07 выбраны базовые решения, сравнение вариантов и правила миграции. На дату исходного анализа их статус был `planned`; текущие статусы ведутся в [очереди](../README.md).
- Для T01 готова методика. Новые тесты A04/A05/A10 не написаны и не запускались в этом аналитическом этапе; результаты физической защиты, аварийного завершения и производительности ещё не подтверждены.
- Пределы большого архива и горизонты 180/365 дней имеют условие выпуска: измерения памяти/скорости и тесты точности. Нельзя считать анализ разрешением просто увеличить константы.
- Банковский API подключается только после подтверждения доступа к нужным личным счетам и истории, согласия/отзыва, правил токенов и цены. Публичная бесплатность определённого API не доказывает доступность всех методов для «Лада».
