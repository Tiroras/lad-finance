# Выполнение примеров главы 3

[Скрипт](prove-examples.mts) вызывает текущие функции предметного слоя для девяти примеров UC-01–UC-09. [Результат выполнения](results.json) хранит возвращённые величины, сообщения отказов и число выполненных утверждений. Денежные значения приведены в целых минимальных единицах валюты, кроме явно обозначенного ряда в RUB.

Из корня проекта при установленных зависимостях выполните:

```sh
node --import tsx output/thesis/research/examples/prove-examples.mts
```

Команда перезаписывает только `results.json` рядом со скриптом. В использованном окружении исполняемый файл Node находится в `/Users/gamkrelidzetimur/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`.

Режим — `domain-only; app not launched`: приложение не запускается, режимы его интерфейса не применяются. Независимые синтетические объекты состояния создаются в оперативной памяти, даты расчётов передаются явно. Хранилища приложения, личные финансовые записи, сеть и устройства не используются.

Примеры охватывают разделение покупки и возврат, валютный перевод с комиссией, взнос и вывод из цели, сверку и датированную корректировку, дневной прогноз, оценку покупки и сохранение, копирование и пересчёт сценария. Утверждения сопоставляют результаты с независимо заданными числовыми значениями и проверяют отказы, отсутствие частичного изменения и сохранность входных объектов. Это воспроизводимый материал к тексту ВКР; он не заменяет проверки экранов, нативного хранилища, биометрии и уведомлений на устройстве.
