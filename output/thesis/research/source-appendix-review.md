# Приложение со ссылкой на исходный код — 6 ноября 2026 года

По запросу пользователя в единые `thesis.md` и `thesis.docx` добавлено приложение 3 «Исходный код мобильного приложения „Лад“». Полный печатный листинг заменён краткой информацией об открытом репозитории и его адресом. В начале главы 3 дана ссылка на новое приложение. Существующие обозначения приложений 1 и 2 и нумерация рисунков сохранены.

## Основания оформления

[ГОСТ 7.32–2017, подраздел 6.17](https://allgosts.ru/01/140/gost_7.32-2017) устанавливает оформление приложений к отчётам о НИР: ссылка из основного текста, последовательность по первым ссылкам, начало с новой страницы, обозначение и отдельный заголовок по центру, общая нумерация страниц. Эти правила использованы для нового приложения на листе А4. В DOCX обозначения всех трёх приложений выводятся прописными буквами.

По пункту 6.17.4 ГОСТ приложения обычно обозначаются буквами. В этой ВКР сохранена ранее принятая цифровая нумерация, используемая профильной методичкой `ВКР_2024_v2 (2).doc`. Цифры 1–3 не объявляются соответствующими буквенной схеме ГОСТ; нумерация не менялась в рамках добавления ссылки.

[ГОСТ Р 7.0.108–2022, пункты 5.1, 5.3.1 и 5.3.5](https://library.csu.ru/media/files/i-culture/7_0_108-2022.pdf) использован для библиографической ссылки на электронный ресурс. В описании указаны наименование репозитория, платформа GitHub, полный URL и дата обращения. Адрес виден при печати и является внешней гиперссылкой в DOCX. Специальные условия доступа не указаны: GitHub API подтвердил, что репозиторий публичный.

Принятая запись:

> Tiroras/lad-finance // GitHub. URL: <https://github.com/Tiroras/lad-finance> (дата обращения: 06.11.2026).

Правила оформления приложения и электронной ссылки сами по себе не устанавливают замену обязательного листинга ссылкой на GitHub. Раздел 7 профильной методички называет «Тексты программ» содержанием приложения 1. Текущая замена выполнена по прямому указанию пользователя; подтверждения, что кафедра принимает такой состав вместо текстов программ, нет. В документ не добавлено утверждение об универсальном разрешении такой замены по ГОСТ.
