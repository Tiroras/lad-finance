# Полный пропуск экскурсии

## Условия

- Режим Demo: `EXPO_PUBLIC_ENABLE_DEMO=true`, очистка выключена.
- Android-эмулятор Pixel_8 (`emulator-5554`), первое приветствие завершено.
- APK собрана из текущих исходников и установлена через `adb install -r`.
- Проверяется профиль «Демо». Финансовые записи не создаются и не редактируются.
- Fresh, `clearState` и сброс профилей не применяются. Прогресс обучения общий
  для приложения; итог проверки — экскурсия пропущена.

## Сценарий

1. Выбрать «Демо» и начать маршрут заново через **Профиль → Обучение**.
   На первом шаге полностью видна кнопка «Пропустить экскурсию».
2. Нажать «Как рассчитана доступная сумма». На втором шаге в окне
   «Всё прозрачно» нажать «Пропустить экскурсию».
   Подсказка и затемнение исчезают; окно остаётся открыто и доступно.
3. Закрыть окно, остановить приложение и запустить снова.
   Карточки «Продолжить обучение» нет.
4. Открыть **Профиль → Обучение**. Видны сообщение о пропуске и
   «Начать экскурсию»; «Продолжить экскурсию» отсутствует.
   Ручной запуск открывает первый шаг.
5. Нажать «Пауза» (доступная подпись «Продолжить позже»).
   Карточка продолжения появляется. «Пропустить экскурсию» в этой карточке
   убирает её, в том числе после остановки и повторного запуска приложения.

Воспроизводимый сценарий: [tour-skip.yaml](../demo/tour-skip.yaml).
Он допускает начатый, завершённый или пропущенный маршрут перед запуском.
Снимки сохраняются в `test-results/mobile/tour-skip/`.

```sh
docker compose run --rm -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 android test --mode demo --device emulator-5554 tests/mobile/demo/tour-skip.yaml
```

Если установленный APK уже соответствует исходникам, допустим `--no-build`.
Проверка не зависит от сумм и календарной даты демоучёта.

Ошибки записи, смена профиля, полный пропуск из каталога и ширины
320/390/1440 px дополнительно проверяются в `tests/e2e/learning.spec.ts`.
Миграция прежнего прогресса и сохранение пропуска проверяются в
`tests/learning.test.ts`. Нативный сценарий не подменяет эти проверки.

## Результат — 5 октября 2026 года

Сценарий успешно выполнен целиком через Maestro MCP на Pixel_8 в Demo.
Визуально проверены кнопка полного пропуска, окно после пропуска и обзор
после повторного запуска. До запуска YAML те же переходы проверены
интерактивно; ошибок приложения не выявлено.

APK: `test-results/mobile/docker/app-demo.apk`, SHA-256:
`60f7dc1f983a9c73fed417180dd4644d68a8a01922ae5038f087576a0d50e920`.
Сборка выполнена `android build --mode demo --abi arm64-v8a` в Docker,
установка — через `adb -s emulator-5554 install -r` с сохранением профилей.
iOS и физическое Android-устройство в этой проверке не использовались.
